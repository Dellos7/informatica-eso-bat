# Atajos de Teclado para el Sistema de Archivos

En informática, dominar el teclado es fundamental para trabajar con rapidez, precisión y comodidad. En el explorador de archivos **Dolphin** (el gestor oficial en **LliureX**), la mayoría de operaciones cotidianas con archivos y carpetas disponen de combinaciones de teclas directas.

---

## 📋 Tabla Resumen de Atajos Imprescindibles

| Atajo de teclado | Acción que realiza en Dolphin / LliureX |
| :--- | :--- |
| <kbd>F2</kbd> | **Renombrar** rápidamente el elemento seleccionado. |
| <kbd>F3</kbd> | **Dividir la vista en dos paneles** independientes. |
| <kbd>F10</kbd> | **Crear una nueva carpeta** al instante. |
| <kbd>F11</kbd> | **Mostrar / ocultar el panel de información** lateral. |
| <kbd>Ctrl</kbd> + <kbd>C</kbd> | **Copiar** el elemento al portapapeles (duplicar). |
| <kbd>Ctrl</kbd> + <kbd>X</kbd> | **Cortar** el elemento (preparar para mover). |
| <kbd>Ctrl</kbd> + <kbd>V</kbd> | **Pegar** el elemento copiado o cortado. |
| <kbd>Ctrl</kbd> + <kbd>A</kbd> | **Seleccionar todos** los elementos de la carpeta. |
| <kbd>Ctrl</kbd> + <kbd>Clic</kbd> | **Selección discontinua** (elementos alternos o salteados). |
| <kbd>Shift</kbd> + <kbd>Clic</kbd> | **Selección continua en bloque** (rango completo de elementos). |
| <kbd>Supr</kbd> *(Delete)* | **Enviar a la papelera** de reciclaje (recuperable). |
| <kbd>Shift</kbd> + <kbd>Supr</kbd> | **Eliminación permanente** e irreversible (¡no pasa por la papelera!). |

---

## 🔍 Explicación por Categorías

### 1. Visualización y Paneles de Dolphin
- **<kbd>F3</kbd> (Doble Panel):** Divide la ventana de Dolphin en dos paneles verticales independientes. Es la forma más cómoda y segura de trasladar o copiar archivos: abres la carpeta de origen a la izquierda y la de destino a la derecha, y simplemente arrastras o usas copiar/pegar.
- **<kbd>F11</kbd> (Panel de Información):** Abre un panel lateral a la derecha donde puedes ver el tamaño exacto, la fecha de modificación, el tipo MIME y una vista previa ampliada del archivo seleccionado.

### 2. Creación y Renombrado Exprés
- **<kbd>F10</kbd> (Crear Carpeta):** Abre directamente el cuadro de diálogo para escribir el nombre de una carpeta nueva sin necesidad de recurrir al menú contextual del ratón.
- **<kbd>F2</kbd> (Renombrar Elemento):** Activa el modo de edición de nombre. En Dolphin tiene la ventaja de que solo selecciona el nombre del archivo y protege la extensión (`.txt`, `.odt`, `.jpg`), evitando que la borres por error.

### 3. Portapapeles (Duplicar vs. Mover)
- **<kbd>Ctrl</kbd> + <kbd>C</kbd> (Copiar):** Mantiene el archivo original en su lugar de origen y guarda una copia exacta en la memoria.
- **<kbd>Ctrl</kbd> + <kbd>X</kbd> (Cortar / Mover):** Prepara el archivo para su traslado definitivo (su icono se vuelve translúcido hasta que lo pegas).
- **<kbd>Ctrl</kbd> + <kbd>V</kbd> (Pegar):** Deposita el elemento copiado o cortado en la carpeta actual donde te encuentres.

### 4. Técnicas de Selección Múltiple
- **<kbd>Ctrl</kbd> + <kbd>A</kbd> (Seleccionar Todo):** Muy útil si deseas vaciar una carpeta o mover todos sus documentos a la vez.
- **<kbd>Ctrl</kbd> + <kbd>Clic</kbd> (Selección Alterna):** Permite hacer clic sobre varios archivos salteados sin perder la selección previa.
- **<kbd>Shift</kbd> + <kbd>Clic</kbd> (Selección Continua):** Haz clic en el primer archivo, mantén pulsada la tecla <kbd>Shift</kbd> (Mayús) y haz clic en el último; todos los archivos intermedios quedarán seleccionados al instante.

### 5. Borrado Seguro vs. Eliminación Irreversible
- **<kbd>Supr</kbd> (Papelera):** El elemento se traslada a la papelera. Si te has equivocado, puedes entrar en ella y pulsar **Restaurar**.
- **<kbd>Shift</kbd> + <kbd>Supr</kbd> (Borrado Inmediato):** 

  > Este comando **destruye el archivo directamente sin pasar por la papelera**. Úsalo únicamente cuando estés 100% seguro de que no volverás a necesitar esa información ni tú ni ningún compañero.
  {: .alert-warning}
