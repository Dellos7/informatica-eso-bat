### 1.2. Licencias de Windows
* **Enunciado:** *En esta sesión se explica que Windows es un sistema operativo de pago, pero yo no he comprado ningún Windows y sin embargo lo tengo en casa. ¿Es esto posible? En caso afirmativo, explica la manera.*
* **Tipo:** 📌 **Objetiva (Apuntes y conceptos de hardware/software)**.
* **Respuesta:**
  **Sí, es totalmente posible.** Las razones principales son:
  1. **Licencia OEM (Preinstalada de fábrica):** Al comprar un ordenador (portátil o de sobremesa), el fabricante (HP, Lenovo, Asus, etc.) ya incluye el coste de la licencia de Windows integrado en el precio final del equipo.
  2. **Actualización gratuita:** Microsoft permitió a los usuarios de versiones anteriores (como Windows 7 u 8) actualizar gratuitamente a Windows 10 y Windows 11.
  3. **Uso sin activar / Versión de evaluación:** Windows se puede descargar e instalar gratuitamente desde la web de Microsoft; funcionará con algunas limitaciones de personalización y una marca de agua.
  4. **Licencias educativas o corporativas:** Proporcionadas gratuitamente al usuario por su centro educativo o lugar de trabajo.

### 2.2. Concepto de distribución Linux y 3 ejemplos
* **Enunciado:** *¿Qué es una distribución de Linux? ¿Puedes nombrar 3 de ellas?*
* **Tipo:** 📌 **Objetiva (Apuntes: Linux y sus distribuciones)**.
* **Respuesta:**
  - **Definición:** Una distribución de Linux (o *distro*) es un sistema operativo completo basado en el núcleo (kernel) de Linux que incluye un conjunto empaquetado de aplicaciones de usuario, utilidades del sistema GNU y un entorno de escritorio gráfico.
  - **3 ejemplos:** **Ubuntu**, **LliureX** y **Debian** (también son válidas: *Fedora, Red Hat, OpenSUSE, Linux Mint, Wifislax*).

---

### 2.3. Distribuciones gratuitas y de pago
* **Enunciado:** *¿Las distribuciones de Linux son todas gratuitas? Busca 3 distribuciones de Linux que sean de pago. Anota el nombre.*
* **Tipo:** 🌐 **Investigación / Técnica**.
* **Respuesta:**
  **No, no todas son gratuitas.** Aunque el núcleo Linux es de código abierto y la gran mayoría de distribuciones son libres y gratuitas, existen distribuciones comerciales orientadas a empresas donde se cobra por licencias, soporte técnico profesional, certificaciones y seguridad.
  - **3 distribuciones de pago / comerciales:**
    1. **Red Hat Enterprise Linux (RHEL)**
    2. **SUSE Linux Enterprise Server (SLES)**
    3. **Oracle Linux** (o versiones comerciales como *Zorin OS Pro* / *Canonical Ubuntu Pro*).

## 3.º) Ejercicios sobre el Sistema Operativo Mac OS

### 3.1. Incidencia de virus en Mac OS
* **Enunciado:** *Los Sistemas operativos Mac OS tienen una baja incidencia de virus, ¿podrías explicar por qué?*
* **Tipo:** 📌 **Objetiva (Apuntes: MacOS)**.
* **Respuesta:**

### 3.3. Tipo de ordenadores, tipo de software y base de Mac OS
* **Enunciado:** *Los sistemas operativos Mac OS, ¿en qué tipo de ordenadores se utilizan? ¿Es un sistema de pago o de software libre? ¿En qué otro sistema operativo está basado?*
* **Tipo:** 📌 **Objetiva (Apuntes: MacOS)**.
* **Respuesta:**
  1. **Tipo de ordenadores:** Se utiliza exclusivamente en ordenadores de sobremesa y portátiles de la marca **Apple** (MacBook Air/Pro, iMac, Mac mini, Mac Studio, Mac Pro).

## 5.º) Ejercicios sobre Android

### 5.1. Sistema base de Android
* **Enunciado:** *¿En qué sistema operativo que ya conoces está basado Android?*
* **Tipo:** 📌 **Objetiva (Apuntes)**.
* **Respuesta:** Está basado en el núcleo (kernel) de **Linux**.

---

### 5.2. ¿Qué es un archivo APK?
* **Enunciado:** *¿Qué es un APK en Android?*
* **Tipo:** 📌 **Objetiva (Apuntes y conceptos móviles)**.
* **Respuesta:**
  Un **APK** (*Android Application Package*) es el formato de archivo empaquetado e instalador de aplicaciones para el sistema operativo Android. Equivale a los archivos `.exe` o `.msi` de Windows, y permite instalar aplicaciones en el móvil tanto desde tiendas alternativas como directamente de forma manual (*sideloading*).

---

### 5.3. Empresa responsable de Android
* **Enunciado:** *¿Qué empresa es la responsable de desarrollar y mejorar Android año tras año?*
* **Tipo:** 📌 **Objetiva (Apuntes)**.
* **Respuesta:** **Google** (Google LLC / Alphabet Inc.).

---

### 5.4. Ventaja de Android frente a un nuevo competidor
* **Enunciado:** *¿Cuál es una ventaja de Android frente a un sistema nuevo que intente salir al mercado?*
* **Tipo:** 📌 **Objetiva (Apuntes)**.
* **Respuesta:**
  Su inmenso **ecosistema de aplicaciones** (con millones de aplicaciones disponibles en Google Play) y su **gran cuota de mercado** global compartida por cientos de fabricantes. Cuando un sistema operativo nuevo intenta entrar al mercado, fracasa si no dispone de apps populares, y los programadores no crean apps si no hay usuarios suficientes (el problema que sufrió Microsoft con Windows Mobile).

## 6.º) Concepto de Aplicación y Ejemplos

### 6.1. ¿Qué es una aplicación?
* **Enunciado:** *¿Qué es una aplicación?*
* **Tipo:** 📌 **Objetiva (Apuntes: Aplicaciones)**.
* **Respuesta:**
  Una aplicación es un **programa informático que se ejecuta sobre un Sistema Operativo** y que es manejado directamente por los usuarios para realizar tareas o satisfacer necesidades específicas (redactar textos, navegar por internet, jugar, editar fotos, etc.).

---

### 6.2. Aplicaciones utilizadas y su función

* **Solución orientativa / Ejemplo completo:**
  1. **Google Chrome / Mozilla Firefox:** Navegador web para buscar información y visitar páginas en Internet.

  3. **GIMP / Photoshop:** Editor de imagen para retocar fotografías, recortar imágenes o realizar carteles.
  4. **WhatsApp / Telegram:** Aplicación de mensajería instantánea para enviar mensajes, fotos y hacer llamadas.

## 8.º) Aplicaciones Web

### 8.1. Multiplataforma en Aplicaciones Web
* **Enunciado:** *¿Una aplicación web es multiplataforma? ¿Por qué?*
* **Tipo:** 📌 **Objetiva (Apuntes: Aplicaciones Web)**.
* **Respuesta:**
  **Sí, es totalmente multiplataforma.** Porque no se instala ni depende directamente del sistema operativo del ordenador, sino que se ejecuta dentro de un **navegador web** (como Chrome, Firefox, Edge o Safari). Dado que los navegadores interpretan los mismos estándares web en cualquier plataforma, la aplicación funciona de forma idéntica en Windows, Linux, Mac OS, Android o iOS.
